# Reset App

Build a mobile app: Use these mockups to make an app that helps quit addictions. i have forgotten to add a shop mockup so u will have to do it on your own. The app uses an AI api to analyze tailored goals and activities to help people quit. optionally, they can connect their calender so they can add a select time to focus on the goals and activities. the app rewards them with xp and gems, which they can use to buy ingame charecters and badges, or real life giftcards - etc. dont add the giftcards tho. The way the app analyzes is that the user will input their triggers, how long they have been addicted, and how often they do it. it works for all - binge eating, smoking, sexual, alchoholism. if the apps not helping, it will direct them to the nearest rehab or addiction recovery or therapist. the whole app should be gamified and users can gain levels if they complete goals and activities.
